Born from
[`the-exfont-is-an-image-in-the-port-not-the-games-exe`](the-exfont-is-an-image-in-the-port-not-the-games-exe.md),
on 2026-11-02: taro asked for a default ExFont for when the project file
names none, and chose, for now, to drop the codes and leave a free
default for later.

It lives in the-advocate, which is public, so it cannot be RM2k's stock
sheet (Enterbrain's) nor EasyRPG's (GPLv3). It is 13 by 4 icons of 12x12,
`A`-`Z` then `a`-`z`; a game counts on the stock one's layout —zodiac,
suits, arrows— when it uses one, so the free one is worth drawing in the
same order.
